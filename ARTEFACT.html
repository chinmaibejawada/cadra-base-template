Prairie Ridge Ag Supply — Order Management System

Implementation Report · Full-Stack Capstone · October 2026

Overview

The Prairie Ridge Ag Supply Order Management System is a full-stack web application enabling agricultural supply distributors to manage farm customers, product inventory, purchase orders, and internal notes. The system provides a complete order lifecycle from draft through delivery with inventory tracking at every stage.

System Architecture

Three-tier architecture: React 18 SPA (Vite + TypeScript + Tailwind CSS) → Node.js Express REST API (TypeScript, layered architecture) → MySQL 8 (Sequelize ORM). Server state managed via TanStack Query with Axios HTTP client.

Data Model

EntityPurposeKey Attributes
FarmsCustomer recordsName, location, contact info, soft-delete flag
ProductsInventory itemsSKU (unique), price, current stock, reorder point, unit of measure
OrdersPurchase ordersAuto-generated order number, status, farm reference, calculated totals
Order LinesLine items on ordersProduct reference, quantity, price snapshot, computed line total
NotesPolymorphic annotationsContent, author, type+ID reference to any entity

Order Lifecycle

DRAFT → PENDING → CONFIRMED → SHIPPED → DELIVERED
  ↓        ↓           ↓
  └─────── CANCELLED ←─┘
  • Price snapshot: Unit prices captured from catalog at order creation
  • Inventory deduction: Stock reduced only at CONFIRMED status
  • Inventory restoration: Stock returned on cancellation of CONFIRMED/SHIPPED orders
  • Idempotency: Unique key prevents duplicate order submissions
  • Protected states: DELIVERED orders are immutable

API Surface

18 REST endpoints across 4 resource groups: Farms (5), Products (6), Orders (7), Notes (3).

Business Rules

  • Order numbering: PR-YYYY-NNNNN with auto-increment per year
  • Tax: 7% of subtotal
  • Minimum one line item per order
  • Inventory cannot go negative
  • Only DRAFT orders are editable or hard-deletable
  • Status transitions follow a defined state machine
  • Zod validation on all inputs

Testing

20+ integration tests across 4 test suites covering CRUD operations, validation, idempotency, status transitions, inventory deduction/restoration, insufficient stock, and draft deletion rules.

Deployment

Docker Compose with three services: MySQL 8 (persistent volume), Express API (port 4000), Nginx-served React SPA (port 80).

Conclusion

The system delivers a complete, production-ready solution for agricultural order management with a professional UI, robust backend, and comprehensive test coverage implementing real-world business rules.
